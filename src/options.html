Capture behaviour

Scrolls the page once before measuring so lazy images load. Turn off for pages that grow forever.

Removing them can also remove pages whose main content is a dialog.

Advanced

Extra time after each scroll for sticky elements to repaint.

ms

Higher values slow the capture down. Chrome caps captures at two per second, so below 500 ms you only hit retries.

ms

Lower values use less memory but downscale tall pages sooner.
